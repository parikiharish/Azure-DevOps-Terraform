# Azure DevOps + Terraform Infrastructure Automation

## Project Overview

This project demonstrates how to provision Azure infrastructure using Terraform and automate deployments using Azure DevOps YAML pipelines.

- Terraform
- Azure CLI
- Azure Repos
- Azure Storage (Remote State)
- Azure Networking
- Azure Key Vault
- Azure Kubernetes Service (AKS)
